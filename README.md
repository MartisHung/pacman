# PacMan 吃豆人

## 專案介紹 / Project Introduction

Pac-Man 是一款經典的吃豆人遊戲。  
Pac-Man is a classic arcade game where the player navigates Pac-Man through a maze to eat all the dots while avoiding ghosts.

## 安裝方法 / Installation

```bash
git clone https://github.com/MartisHung/pacman.git
```
##　編譯檔案 / Compile the file
- clang/clang++
```bash
clang++ p_main.cpp -o PacMan.cpp
```
- gcc/g++
```bash
g++ p_main.cpp -o PacMan.cpp
```
### 執行檔案 / Execute Game
```bash
./PacMan.cpp
```

### 控制方式 / Controls

- 使用方向鍵或 WASD 鍵移動。/ Use arrow keys or WASD to move.
- 避免幽靈，吃掉所有點數以過關。/ Avoid ghosts and eat all dots to win.

## 功能說明 / Features

- 中英雙語界面。/ Bilingual Chinese-English interface.
- 隨機AI敵人移動。/ Random AI enemy movements.
- 簡易地圖設計。/ Simple map design.
